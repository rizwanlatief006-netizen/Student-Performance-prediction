# Student Performance Prediction System Using Machine Learning

## Project Overview
This project predicts students' academic performance using Machine Learning.

The system predicts three categories:
1. At Risk
2. Average
3. Good

The project uses a Streamlit web application.

## Algorithms Used
1. Random Forest
2. Support Vector Machine (SVM)
3. Gradient Boosting

## Technologies Used
- Python
- Machine Learning
- Scikit-learn
- Pandas
- Streamlit
- Joblib

## Project Files
- app.py: Main application file.
- student_performance_model.pkl: Trained machine learning model.
- model_comparison.csv: Model comparison results.
- requirements.txt: Required Python libraries.
- README.md: Project information.

## Installation Steps

Step 1: Install Python.

Step 2: Open Command Prompt inside the project folder.

Step 3: Install the required libraries:

python -m pip install -r requirements.txt

Step 4: Run the application:

python -m streamlit run app.py

Step 5: Open the local website address shown in the terminal.

## How to Use
1. Open the website.
2. Enter student information.
3. Click Predict Student Performance.
4. View the prediction result.
5. Compare the machine learning algorithms.
